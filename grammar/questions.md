# Yes/No Questions & Question Words — Câu Hỏi

## Yes/No Questions

### Pattern 1: Verb + **không**?
```
Bạn ăn cơm không?      → Do you eat rice? (or: Are you eating?)
Bạn biết không?         → Do you know?
Bạn thích không?        → Do you like it?
```

Answer:
- **Có** (yes, do) or **không** (no, don't)
- Or repeat the verb: **Ăn.** / **Không ăn.**

### Pattern 2: **Có** + Verb + **không**? (formal/emphatic)
```
Bạn có ăn cơm không?    → Do you eat rice? (more formal)
Anh có đi không?        → Are you going?
```

### Pattern 3: **Đã** + Verb + **chưa**? (yet/still)
```
Bạn ăn cơm chưa?        → Have you eaten yet? (lit: eat rice yet?)
Bạn đi chưa?            → Have you gone yet?
```

Answer:
- **Rồi** (already = yes) or **Chưa** (not yet = no)

### Pattern 4: Statement + **à/ư**? (surprise/skepticism)
```
Bạn không ăn à?         → You're not eating? (surprised)
Anh đi thật à?          → You're really going? (unexpected)
```

## Question Words

| Word | IPA | Meaning | Example |
|------|-----|---------|---------|
| gì | /zi˨˩/ | what | Cái gì? (What thing?) |
| ai | /ʔaj˧˧/ | who | Ai đó? (Who's that?) |
| đâu | /ʔɗəw˧˧/ | where | Ở đâu? (Where?) |
| nào | /naːw˨˩/ | which | Cái nào? (Which one?) |
| sao | /saːw˧˧/ | why/how | Tại sao? (Why?) |
| bao nhiêu | /ɓaːw˧˧ ɲiəw˧˧/ | how many | Bao nhiêu tiền? (How much?) |
| bao giờ | /ɓaːw˧˧ zəː˨˩/ | when (future) | Bao giờ đi? (When go?) |
| khi nào | /xi˧˧ naːw˨˩/ | when | Khi nào về? (When return?) |
| thế nào | /tʰe˧˥ naːw˨˩/ | how | Thế nào? (How is it?) |
| mấy | /məj˧˥/ | how many (small) | Mấy tuổi? (How old?) |
| có...không | /kɔ˧˥ ... xəwŋ͡m˧˧/ | "is there?" | Có cơm không? (Is there rice?) |

## Question Word Order

Question word stays **in situ** (same position as the answer):

```
Answer:  Tôi đi Hà Nội.           → I go to Hanoi.
Question: Bạn đi đâu?             → You go where?

Answer:  Tôi ăn cơm.              → I eat rice.
Question: Bạn ăn gì?              → You eat what?
```

## Common Mistakes

- 🇧🇷 Moving question word to front (like English). Keep **in situ**: "Bạn đi đâu?" not "Đâu bạn đi?"
- Confusing **bao giờ** (when future) vs **khi nào** (when, more general)
- Using **không** for "yet" questions — use **chưa**: "Bạn ăn chưa?" not "Bạn ăn không?" (that asks "do you want to eat?")
