# Vietnamese Classifiers — Từ Chỉ Loại

## Key Rule
Vietnamese requires a classifier between number/demonstrative and noun. Like Portuguese "o/a" but more specific.

| Classifier | IPA | Use for | Example |
|------------|-----|---------|---------|
| cái | /kaj˧˥/ | inanimate objects (general) | cái bàn (a table) |
| chiếc | /tɕiək˧˥/ | vehicles, furniture (formal/singular) | chiếc xe (a car) |
| con | /kɔn˧˧/ | animals, children, some objects | con chó (a dog), con dao (a knife) |
| quả / trái | /kwaː˧˥/ / /tʂaːj˧˥/ | fruits, round objects | quả táo (an apple) |
| cây | /kəj˧˧/ | long objects, plants, sticks | cây bút (a pen), cây tre (a bamboo) |
| tờ | /təː˨˩/ | flat objects (paper, maps) | tờ báo (a newspaper) |
| cuốn / quyển | /kuən˧˥/ / /kwiən˧˥/ | books, bound objects | cuốn sách (a book) |
| ngôi | /ŋoj˧˧/ | buildings, celestial bodies | ngôi nhà (a house), ngôi sao (a star) |
| tòa | /twaː˨˩/ | large buildings, institutions | tòa nhà (a building) |
| chiếc | /tɕiək˧˥/ | vehicles, shoes, singular items | chiếc giày (a shoe) |
| bức | /ɓɨk˧˥/ | flat images (photos, paintings) | bức tranh (a painting) |
| lá | /laː˧˥/ | letters, documents | lá thư (a letter) |
| hạt | /haːk˧˨ʔ/ | grains, seeds, small round things | hạt gạo (a grain of rice) |

## Portuguese Speaker Notes

- **Pense como artigo definido/indefinido:** "cái" ≈ um/uma genérico pra objeto.
- **"con" não é só animal:** faca (con dao), estrada (con đường), rio (con sông) — objetos alongados/animados.
- **"cái" é o curinga:** quando não souber qual classifier usar, tente "cái" — geralmente funciona pra objetos inanimados.
- **"chiếc" é mais formal que "cái":** "chiếc xe" = formal, "cái xe" = colloquial.

## Examples

```
một cái bàn        → uma mesa
ba con chó         → três cachorros
hai quả cam        → duas laranjas
những ngôi sao     → as estrelas
cái gì thế?        → que coisa é essa?
```

## Common Mistakes

- 🇧🇷 Esquecer classifier → "một bàn" ERRADO → "một cái bàn" CORRETO
- 🇧🇷 Usar "con" pra tudo → soa estranho. Objetos inanimados comuns usam "cái".
- 🇧🇷 Confundir "quả" vs "trái": "quả" (norte), "trái" (sul) — mesma coisa, regional.
