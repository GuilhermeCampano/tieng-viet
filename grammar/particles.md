# Sentence-Final Particles — Tiểu Từ Cuối Câu

## Key Rule
Vietnamese uses sentence-final particles to convey mood, politeness, certainty, and emotion. No direct equivalent in English.

| Particle | IPA | Function | Example |
|----------|-----|----------|---------|
| không | /xəwŋ͡m˧˧/ | yes/no question (end) | Bạn đi không? (Are you going?) |
| à | /ʔaː˨˩/ | surprised question | Bạn đi à? (Oh, you're going?) |
| ư | /ʔɨ˧˧/ | skeptical question | Bạn đi ư? (Really? You're going?) |
| nhé | /ɲɛ˧˥/ | suggestion/request (soft) | Bạn đi nhé. (Go, okay?) |
| nhỉ | /ɲi˧˦ˀ˥/ | wondering/sharing | Đẹp nhỉ? (Beautiful, isn't it?) |
| đấy | /ʔɗəj˧˥/ | emphasis, certainty | Nó đi đấy. (He IS going.) |
| mà | /maː˨˩/ | insistence, contradiction | Tôi biết mà. (I DO know.) |
| thế | /tʰe˧˥/ | "like that", questioning | Sao thế? (Why's that?) |
| ạ | /ʔaː˧˨ʔ/ | polite/respectful (southern) | Dạ, em đi ạ. (Yes, I'll go.) |
| cơ | /kəː˧˧/ | contrary to expectation | Ngon cơ! (It IS tasty!) |
| chứ | /tɕɨ˧˥/ | obvious, rhetorical | Đi chứ? (Going, right?) |
| vậy | /vəj˧˨ʔ/ | confirmation | Vậy à? (Is that so?) |

## Common Patterns

- Statement + **à** → Surprised question: "Bạn là người Brasil à?" (Oh, you're Brazilian?)
- Statement + **nhé** → Soft suggestion: "Mai gặp lại nhé." (Let's meet tomorrow, yeah?)
- Question + **thế** → "Sao lại thế?" (How come?)
- Verb + **không** → Yes/no: "Ăn cơm không?" (Eat rice? / Wanna eat?)
- Verb + **chưa** → "Have you... yet?": "Ăn cơm chưa?" (Eaten yet?)

## Common Mistakes

- Mixing **à** and **ư**: **à** = neutral surprise, **ư** = polite skepticism
- Forgetting **ạ** with elders in the South — can sound rude without it
- **nhé** vs **nhỉ**: **nhé** = suggestion to listener, **nhỉ** = shared reflection
