# Reduplication — Từ Láy

## Key Rule
Vietnamese reduplicates to create new meanings, intensify, or add rhythm. Very common in speech and literature.

## Types

### Full reduplication (identical)
| Root | Reduplicated | Meaning |
|------|-------------|---------|
| người (person) | người người | everybody (one by one) |
| ngày (day) | ngày ngày | day after day |
| đi (go) | đi đi | keep going |
| từ từ | từ từ | slowly (lit: "from from") |

### Tone/rhyme change reduplication
| Base | Reduplicated | Meaning shift |
|------|-------------|---------------|
| đỏ (red) | đo đỏ | reddish (less intense) |
| xanh (blue/green) | xanh xanh | greenish |
| sạch (clean) | sạch sạch | fairly clean |

### Rhyming reduplication (từ láy bộ phận)
| Word | Meaning | Notes |
|------|---------|-------|
| lung linh | shimmering, twinkling | sound symbolism |
| lấp lánh | sparkling | |
| rực rỡ | bright, brilliant | |
| nhỏ nhắn | small and cute | |
| vui vẻ | cheerful, happy | |
| buồn bã | sad, sorrowful | |
| lộn xộn | messy, disorderly | |
| ấm áp | warm (cozy) | |
| nóng nực | hot, sweltering | |
| lạnh lẽo | cold, desolate | |

### Opposite-meaning pairs
| Pair | Meaning |
|------|---------|
| lớn (big) + nhỏ (small) | size, everything |
| cao (high) + thấp (low) | height, status |
| phải (right) + trái (left) | direction |
| nam (male) + nữ (female) | gender |

These often appear as compounds: **to nhỏ** (big-small = everything), **đi lại** (go-come = movement/travel).

## Portuguese Speaker Notes

- Like Portuguese diminutives/augmentatives but more systematic
- "đỏ" = red, "đo đỏ" = reddish (like "avermelhado")
- Rhyming reduplication pairs are lexicalized — learn them as vocabulary items
- Reduplication often carries positive connotation (cute, pleasant)

## Examples

```
Trời xanh xanh.              → The sky is bluish.
Cô ấy vui vẻ.               → She's cheerful.
Ngày ngày tôi đi học.       → Day after day I go to school.
Đi đi lại lại.               → Pace back and forth.
Nhà cửa lộn xộn quá.        → The house is so messy.
```
