# Comparatives — So Sánh

## Key Rule
Vietnamese uses **hơn** (more/than) and **nhất** (most) without changing the adjective.

## Comparative: Adj + **hơn**

```
Noun A + [adjective] + hơn + Noun B
```

### Examples
```
Tôi cao hơn nó.           → I am taller than him.
Cô ấy đẹp hơn tôi.       → She is prettier than me.
Xe này rẻ hơn xe kia.    → This bike is cheaper than that one.
Học tiếng Việt khó hơn tiếng Anh?  → Is learning Vietnamese harder than English?
```

### With measure: **hơn** can be modified
```
Nhiều hơn                → more (quantity)
Ít hơn                   → less
Tốt hơn                  → better
Xấu hơn                  → worse
Đắt hơn                  → more expensive
Rẻ hơn                   → cheaper
```

### "More than [number]"
```
Hơn mười người.          → More than 10 people.
Hơn một năm.             → More than a year.
```

## Superlative: **nhất**

```
Noun + [adjective] + nhất (+ [group])
```

### Examples
```
Nó cao nhất.             → He is the tallest.
Cô ấy đẹp nhất lớp.     → She is the prettiest in class.
Món này ngon nhất.       → This dish is the most delicious.
Hà Nội lớn nhất Việt Nam. → Hanoi is the biggest city in Vietnam.
```

## Equality: **bằng** / **như** / **giống**

```
Noun A + [adj] + bằng/như + Noun B
```

### Examples
```
Tôi cao bằng nó.         → I am as tall as him.
Cái này rẻ như cái kia.  → This is as cheap as that.
Em giống mẹ.             → The child resembles the mother.
```

## Less: **kém** / **không...bằng**

```
Noun A + kém + [adj] + hơn + Noun B
Noun A + không + [adj] + bằng + Noun B
```

### Examples
```
Nó kém thông minh hơn tôi.  → He is less intelligent than me.
Cô ấy không đẹp bằng chị.  → She is not as pretty as her sister.
```

## "The more... the more" Structure
Càng + [adj/verb] + càng + [adj/verb]

```
Càng học càng giỏi.       → The more you study, the better you get.
Càng đông càng vui.       → The more (people), the merrier.
```

## Common Mistakes

- Adding "more" adjective: "more taller" → ERRADO. Just **cao hơn** not **hơn cao hơn**
- Word order: Adj comes BEFORE **hơn/nhất**, not after
- Confusing **bằng** (equality) vs **giống** (similar appearance): "Cao bằng" = as tall as, "Giống" = looks like
