# Directional Verbs — Động Từ Chỉ Hướng

## Key Rule
Vietnamese uses directional verbs after main verbs to indicate movement direction. These function like phrasal verbs in English (go up, come down, go out, etc.)

| Direction | Verb | IPA | Meaning |
|-----------|------|-----|---------|
| up | lên | /leŋ˧˧/ | upward, increase |
| down | xuống | /suəŋ˧˥/ | downward, decrease |
| in | vào | /vaːw˨˩/ | enter, toward speaker's location |
| out | ra | /zaː˧˧/ | exit, outward, northward |
| over | qua | /kwaː˧˧/ | across, past |
| back | lại | /laːj˧˨ʔ/ | toward, back to |
| away | đi | /ɗi˧˧/ | away, off |

## Core Structure

```
Main Verb + Directional
```

### Simple movement
```
Đi lên.              → Go up.
Đi xuống.            → Go down.
Đi vào.              → Go in.
Đi ra.               → Go out.
Chạy qua.            → Run across.
Quay lại.            → Turn back/return.
Cất đi.              → Put away.
```

### With object
```
Lấy sách ra.          → Take the book out.
Mang đồ vào.          → Bring the things in.
Đặt ly xuống.         → Put the cup down.
Treo áo lên.          → Hang the shirt up.
```

### Figurative / Extended meanings
```
Nói ra               → speak out (utter)
Nghĩ ra              → think of (come up with)
Thêm vào             → add in
Bớt đi               → reduce (take away)
Lớn lên              → grow up
Nhỏ lại              → shrink (become smaller)
Tăng lên             → increase
Giảm xuống           → decrease
Chết đi              → die (away)
Sống lại             → come back to life
```

## Important Pairs

| Pair | Meaning | Example |
|------|---------|---------|
| lên - xuống | up - down | Đi lên / Đi xuống |
| vào - ra | in - out | Chạy vào / Chạy ra |
| qua - lại | across - back | Đi qua cầu (cross bridge), Đi lại (come and go) |
| đi - lại | away - toward | Mang đi (take away), Mang lại (bring here) |

## Combined with Aspect Markers
```
Đi xuống đi!            → Go down! (emphasis/repetition)
Lấy cái này ra đây.    → Take this out here.
```

## Common Mistakes

- Word order: Directional AFTER main verb, not before: "đi lên" NOT "lên đi" (that's "go up already!")
- Mixing **vào** vs **trong**: **vào** is movement direction "into", **trong** = "inside" (static)
- **ra** can mean "northward" (to Hanoi) and **vào** can mean "southward" (to Saigon) — "ra Hà Nội, vào Sài Gòn" — historical convention
