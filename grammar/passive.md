# Passive Voice — Bị / Được

## Key Rule
Vietnamese passive uses **bị** (negative) or **được** (positive) before the main verb. Unlike English "be + past participle", VI passive marks whether the action is **fortunate** or **unfortunate**.

| Marker | Meaning | Connotation |
|--------|---------|-------------|
| bị | to suffer, get (negative) | unfortunate, unwanted |
| được | to receive, get (positive) | fortunate, wanted |

## Structure

```
Subject + bị/được + [Agent] + Verb
```

## Examples

### Bị (negative/unwanted)
```
Nó bị đánh.              → He got hit. (suffered)
Tôi bị lừa.              → I was tricked.
Xe bị hỏng.              → The bike broke down.
Tôi bị cảm.              → I caught a cold.
```

### Được (positive/wanted)
```
Nó được khen.            → He was praised.
Tôi được mời.            → I was invited.
Em được đi chơi.         → The child got to play.
Tôi được tặng quà.       → I was given a gift.
```

### With agent
```
Tôi bị nó đánh.          → I was hit by him.
Tôi được mẹ cho tiền.    → I was given money by mom.
```

## Important Nuance

- **No passive = neutral**: "Cửa mở" (door opens) — neither passive nor active. Vietnamese often uses active voice even where English would use passive.
- **bị/được** are closer to "suffer/enjoy" than true passive markers.
- Many verbs are inherently neutral; context determines if **bị** or **được** should be used.

## Common Mistakes

- Using passive where Vietnamese prefers active: "Cơm đã ăn" (rice was eaten) sounds odd → prefer "Đã ăn cơm rồi."
- Forgetting **bị** for negative events: "Tôi đánh" = "I hit" (not "I got hit")
- Overusing passive like English — Vietnamese avoids passive unless fortunate/unfortunate nuance is important
